Medowdog Pipeline

Six scripts in fixed order, one price file per ticker rewritten in place, and a cost measurement that depends on the step that depends on it.

What the picture is for

The lane is a single file, not a stage. 2_volatility.py and 3_ewmac_calculator.py read the downloader's CSV and write the same path back. A second file in data/SPY/ means the per-file scripts process the older one and say nothing, while 4_correlation.py dies at weights sum to 2.0000.

The amber path is a cycle, so neither end can go first. Script 6 measures the trade sizes that script 5 divides the $1 commission minimum by; script 5 measures the cost per share that script 6 deducts from compounding equity. On a cold start, run 6 once with no cost file — it reports gross — then 5, then 6 again.

Script 5 sits outside the bracket because of the clock, not the dependencies. The quote stream returns IBKR's −1 sentinel when the US market is closed, so it runs mid-session at 23:30 SGT while everything else runs after the close.
